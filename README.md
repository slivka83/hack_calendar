# hack_calendar

Одностраничный сайт с диаграммой Ганта по ML-соревнованиям и хакатонам для телеграм-канала. Работает офлайн, без зависимостей.

## Файлы

- `hacks.db` — SQLite-база: события, фазы, треки, теги треков (источник данных)
- `data.js` — снимок событий из БД, который читает сайт
- `index.html` — сам сайт (без зависимостей, работает офлайн)

## База данных

`hacks.db` — источник данных проекта (SQLite, без зависимостей):

| Таблица | Что хранит |
| --- | --- |
| `events` | соревнование/хакатон: тип, название, ссылка, даты, регистрация, приз, участие, формат, язык, `declared_tracks` (когда одним треком объявлено «N кейсов») |
| `phases` | этапы события (`label`, `start`, `end`, порядок) |
| `tracks` | треки/кейсы/задачи события: `label` («Кейс 1», «Задача»), `title` (без тега и метки), `raw` (исходная строка) |
| `track_tags` | направления треков: `NLP`, `CV`, `CLF`, `ML`, `RAG`, … |

Есть представление `event_tracks` — событие, тип, метка трека, описание и теги одной строкой. Примеры запросов:

```sql
-- все треки с тегами
SELECT * FROM event_tracks;

-- сколько треков по каждому направлению
SELECT tag, count(*) FROM track_tags GROUP BY tag ORDER BY count(*) DESC;

-- события с призом от 1 млн, ближайшие первыми
SELECT name, prize, start FROM events WHERE prize LIKE '%000 000%' ORDER BY start;
```

`data.js` — снимок событий из `hacks.db`, который читает сайт. Генератора в
репозитории нет: при правках `hacks.db` снимок обновляется вручную (или скрипт
восстанавливается из истории git).

## Возможности сайта

- тёмная и светлая темы (правый переключатель, выбор запоминается);
- периоды отображения: 6 мес, 1 год, 2 года, все — последние N месяцев от
  последнего месяца данных; по умолчанию 6 мес;
- чипсы под названием: теги направлений треков (NLP, CV, ML, …), приз, формат
  (онлайн / офлайн / гибрид), соло/команда;
- колонка названий подстраивается под самую длинную строку — названия не
  обрезаются (на экранах ≤600px колонка фиксированная);
- иконки справа от названия: страница события, добавление в Google Календарь,
  скачивание `.ics`;
- компактная подсказка при наведении на полоску: название, даты, регистрация,
  фазы; полная карточка события — по клику на полоску, название или маркер
  регистрации (`Esc`, крестик или клик по фону закрывают);
- в карточке — добавление в календарь: ссылки Google (событие и, если есть,
  дедлайн регистрации) и скачивание `.ics` (Яндекс, Apple, Mail.ru и др.);
  файл собирается в браузере, интернет для него не нужен;
- поиск по названию, задаче и типу; `/` — фокус на поиске, `Esc` — сброс;
- шкала месяцев или годов (с равным масштабом по дням), линия «сегодня»,
  маркеры дедлайна регистрации, подсветка строки названия при наведении;
- адаптивность: масштаб шкалы подстраивается под ширину окна.

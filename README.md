# hack_calendar

Одностраничный сайт с диаграммой Ганта по ML-соревнованиям, хакатонам и мероприятиям для телеграм-канала. Работает офлайн, без зависимостей.

## Файлы

- `hacks.db` — SQLite-база: события, фазы, треки, теги треков, материалы (источник данных)
- `data.js` — снимок событий из БД, который читает сайт
- `index.html` — сам сайт (без зависимостей, работает офлайн)
- `favicon.svg` — иконка вкладки и логотип (эмодзи OpenMoji, CC BY-SA 4.0)
- `icons/` — иконки сайтов событий (файл на домен), показываются в карточке

## База данных

`hacks.db` — источник данных проекта (SQLite, без зависимостей):

| Таблица | Что хранит |
| --- | --- |
| `events` | событие: `category` (`comp` — соревнование/хакатон, `event` — мероприятие), тип (`СОР`/`ХАК` или `КОНФ`/`МИТАП`/`ФЕСТ`/`СЕМИНАР`/`ВОРКШОП`/`ВЕБИНАР`), название, ссылка, даты, время, описание, регистрация, приз, участие, формат, язык, `declared_tracks` (когда одним треком объявлено «N кейсов»), `added` (дата добавления в БД, ISO) |
| `phases` | этапы события (`label`, `start`, `end`, порядок) |
| `tracks` | треки/кейсы/задачи события: `label` («Кейс 1», «Задача»), `title` (без тега и метки), `raw` (исходная строка) |
| `track_tags` | направления треков: `NLP`, `CV`, `CLF`, `ML`, `RAG`, … |
| `links` | ссылки по событию: трансляции (`stream`), решения участников (`solutions`), церемонии (`ceremony`), видео (`video`), статьи (`article`) |
| `talks` | программа докладов мероприятия: время, название, спикер, порядок |

Есть представление `event_tracks` — событие, тип, метка трека, описание и теги одной строкой. Примеры запросов:

```sql
-- все треки с тегами
SELECT * FROM event_tracks;

-- сколько треков по каждому направлению
SELECT tag, count(*) FROM track_tags GROUP BY tag ORDER BY count(*) DESC;

-- события с призом от 1 млн, ближайшие первыми
SELECT name, prize, start FROM events WHERE prize LIKE '%000 000%' ORDER BY start;
```

`data.js` — снимок событий из `hacks.db`, который читает сайт. Генератора из
БД в репозитории нет: при правках `hacks.db` снимок обновляется вручную (или
разовым скриптом вне репо); формат выгрузки менять только вместе с полями,
читающими её в `index.html`.

## Возможности сайта

- вкладки «Соревнования» (диаграмма Ганта) и «Мероприятия» (классический
  месячный календарь): общий поиск, выбор вкладки запоминается между визитами;
  фильтры «Актуальные»/«Записаться» показываются только у соревнований,
  в календаре мероприятий вместо них — фильтр формата «Все / Онлайн / Офлайн»
  (гибридные события проходят и «Онлайн», и «Офлайн»);
- календарь мероприятий — сквозная лента недель, прокручивается колесом мыши;
  неделя на стыке месяцев общая (месяцы как бы накладываются), их разделяет
  ступенька бордовой линии 1px, доходящая до левого края и разделяющая заодно
  подписи месяцев, пустых ячеек нет; шапка дней недели одна, закреплена сверху
  и разделена линиями между днями, подпись месяца — вертикальная полоса слева;
  выходные затемнены, сегодняшний день — диагональной штриховкой; при открытии
  лента прокручивается к текущему месяцу; кнопки ‹ / › листают по месяцам
  (первый день месяца встаёт под шапку), «Сегодня» возвращает к текущему
  (стрелки ←/→ на клавиатуре); чипсы событий
  окрашены по формату (онлайн/офлайн/гибрид), многодневные повторяются в каждом
  дне, каждая дата
  встречается один раз, по клику открывается
  карточка, при наведении —
  подсказка; поиск и фильтры, если результат не на экране, переходят к месяцу
  первого совпадения;
- тёмная и светлая темы (правый переключатель, выбор запоминается);
- периоды отображения: 6 мес, 1 год, 2 года, все — последние N месяцев от
  последнего месяца данных; по умолчанию 6 мес;
- фильтры «Актуальные» (событие ещё не закончилось — текущие и будущие) и
  «Записаться» (регистрация ещё открыта) — только на вкладке «Соревнования»;
  включаются независимо, комбинируются с поиском;
- чипсы под названием: теги направлений треков (NLP, CV, ML, …), приз, формат
  (онлайн / офлайн / гибрид), соло/команда;
- колонка названий подстраивается под самую длинную строку — названия не
  обрезаются (на экранах ≤600px колонка фиксированная);
- иконки справа от названия: страница события, добавление в Google Календарь,
  скачивание `.ics`;
- компактная подсказка при наведении на полоску: название, даты (у однодневных
  событий — одна), время, регистрация, фазы; полная карточка события — по клику
  на полоску, название или маркер регистрации (`Esc`, крестик или клик по фону
  закрывают); карточка: слева иконка сайта события из
  `icons/` (если файла нет, иконка не показывается), описание, треки под
  заголовком «🏷️ Треки:» («🏷️ Темы:» у мероприятий), приз, участие, формат и
  экспорт в календарь; «🔗 Открыть страницу события» и материалы (трансляции,
  решения, церемонии, видео, статьи) — в правой колонке у соревнований
  (разделитель — вертикальная линия), иначе ниже; справа — программа докладов
  «📋 Программа:» (время — название) шириной 3/5, если она есть; без программы
  и материалов карточка в одну колонку (колонки соревнований на узких экранах
  складываются);
- в карточке — добавление в календарь: ссылки Google (событие и, если есть,
  дедлайн регистрации) и скачивание `.ics` (Яндекс, Apple, Mail.ru и др.);
  файл собирается в браузере, интернет для него не нужен;
- поиск по названию, задаче и типу; `/` — фокус на поиске, `Esc` — сброс;
- шкала месяцев или годов (с равным масштабом по дням), линия «сегодня»,
  маркеры дедлайна регистрации, подсветка строки названия при наведении;
- адаптивность: масштаб шкалы подстраивается под ширину окна.

# AGENTS.md

Офлайн-сайт с диаграммой Ганта (один `index.html`, без сборки, зависимостей и
сервера). Тестов, линтеров и CI нет. Весь контент и UI — на русском,
формулировки держать на русском.

## Схема БД (hacks.db)

- `hacks.db` — источник данных, `data.js` — его снимок для сайта. Генераторов
  в репо нет: при правках `hacks.db` обновлять `data.js` нечем — придётся
  восстановить генератор из git.
- `events` — событие; `declared_tracks` = «N кейсов» одной строкой
  (`Лидеры цифровой трансформации 2026` → 20).
- `phases`, `tracks` (`label`/`title`/`raw`), `track_tags` (`NLP`, `CV`, …),
  вьюха `event_tracks`. Теги извлекаются из `[...]` в начале задачи.

## Фронтенд (index.html)

- Данные приходят глобалом `HACKS` из `data.js`, без fetch и сборки; работает и
  по `file://`. Формат выгрузки менять только вместе с полями, читающими её в
  `index.html`.
- По горизонтали прокрутки нет: `layout()` в `build()` вписывает весь период в
  ширину окна (`--timeline-w`, шаг `--day-w`), `--corner-w` — так же на лету в
  `computeCornerWidth()`. Значения в CSS — только фолбэк до первого рендера,
  правка CSS ничего не даст.
- Колонка имён подстраивается под самую длинную строку «название + иконки»
  (замер по `scrollWidth`), названия не обрезаются; на окнах ≤600px — фикс.
  200px.
- По вертикали — обычная прокрутка внутри `.gantt-scroll`; высота строк
  фиксированная (`--row-h`, 72px; на узких экранах 56px), шапка и колонка имён
  липкие.
- Кнопки периода (6 мес … Все; по умолчанию 6 мес, «Все» — крайняя справа)
  отсчитывают последние N месяцев от последнего месяца данных; события, не
  помещающиеся в окно целиком (включая фазы), не показываются — полосы не
  обрезаются.
- Гранулярность оси: месяцы, пока их ≤ 12 и ширина месяца ≥ 36px, иначе годы;
  ширины ячеек всегда пропорциональны дням (единый масштаб), в годовом режиме
  ось выравнивается по границам лет; позиции полос/линий/«сегодня» считает
  `xOf()` по `CELLS`.
- Чипсы держатся в одну строку: `fitChips()` уменьшает шрифт; чипсой «N треков»
  строка не показывается (число треков есть только в БД как `declared_tracks`).
- Экспорт в календарь — в карточке: ссылки Google (`googleUrl()`, конец +1 день
  — конец эксклюзивен) и скачивание `.ics` (`buildICS()`/`downloadICS()`: VEVENT
  на период + VEVENT «рег. до …», экранирование `, ; \`, фолдинг по 75 октетов,
  `Blob` + `URL.createObjectURL` — без сети). Те же действия доступны иконками
  справа от названия (`CAL_SVG`, `ICS_SVG`; класс `.cal`).
- Две формы деталей: при наведении на полоску — компактный тултип (`renderTip`:
  название, «📅 С … по …», «⏳ Рег. до …», строки фаз «🏁 Финал 27.11 – 29.11»);
  по клику на полоску, название (псевдоссылка с пунктиром, клик не по всей
  ячейке) или маркер (или Enter/Space на полоске) — полная карточка в модалке
  (`renderFull`, `openModal`/`closeModal`; Esc, клик по фону и крестик закрывают,
  внизу ссылка «Открыть страницу события»). Иконки рядом с названием клик не
  перехватывают: страница события (`LINK_SVG`), Google, `.ics`.

  сети недоступен — не скрейпить напрямую; при дозагрузке использовать
  Telethon-сессию из `../tg_chat_aggregator` (нужен оплаченный прокси из его
  `.env`), только чтение и с паузами.

# AGENTS.md

Офлайн-сайт с диаграммой Ганта (один `index.html`, без сборки, зависимостей и
сервера). Тестов, линтеров и CI нет. Весь контент и UI — на русском,
формулировки держать на русском.

## Схема БД (hacks.db)

- `hacks.db` — источник данных, `data.js` — его снимок для сайта. Генератора
  из БД в репо нет: снимок обновляется вручную или разовым скриптом вне репо;
  формат выгрузки менять только вместе с полями, читающими её в `index.html`.
- `events` — событие; `category` = `comp` (соревнование/хакатон, вкладка
  «Соревнования») или `event` (мероприятие, вкладка «Мероприятия»); `type` —
  `СОР`/`ХАК` у соревнований и `КОНФ`/`МИТАП`/`ФЕСТ`/`СЕМИНАР`/`ВОРКШОП`/
  `ВЕБИНАР` у мероприятий; `time` — время начала строкой («17:00 мск», может
  быть пусто); `description` — краткое описание для карточки; `declared_tracks`
  = «N кейсов» одной строкой (`Лидеры цифровой трансформации 2026` → 20),
  `added` — дата добавления события в БД (ISO, у событий до 02.10.2026 пусто).
- `phases`, `tracks` (`label`/`title`/`raw`), `track_tags` (`NLP`, `CV`, …),
  `links` (`kind` = `stream`/`solutions`/`ceremony`/`video`/`article` —
  трансляции и материалы по событию, `position` — порядок внутри события),
  `talks` (`time`/`title`/
  `speaker` — программа докладов мероприятия, `position` — порядок; `time`
  может быть пустым, если на странице нет таймингов — программу добавляем
  всегда, со всем, что есть), вьюха
  `event_tracks`. Теги
  извлекаются из `[...]` в начале задачи.

## Фронтенд (index.html)

- Данные приходят глобалами `HACKS` (соревнования) и `MEETUPS` (мероприятия)
  из `data.js`, без fetch и сборки; работает и по `file://`. Формат выгрузки
  менять только вместе с полями, читающими её в `index.html`.
- Вкладки «Соревнования»/«Мероприятия» (`#tabGroup`, `state.tab`) переключают
  датасет (`DATASETS.comp` — из `HACKS`, `DATASETS.event` — из `MEETUPS`) и
  вид: соревнования — диаграмма Ганта, мероприятия — классический календарь
  (`#calendarWrap`, `buildCalendar`); поиск общий, фильтры «Актуальные» и
  «Записаться» показываются только у соревнований (в календаре мероприятий
  скрыты);
  выбранная вкладка запоминается (`localStorage`, ключ `hc-tab`).
- Календарь мероприятий — сквозная лента недель (`#calendarWrap`,
  `buildCalendar`): месяцы с результатами и промежуточные между ними идут
  подряд одной сеткой 7×N без пустых ячеек; неделя на стыке общая — месяцы
  «накладываются», и бордовая линия 1px (`cal-hline`/`cal-vline`, цвет
  `--cal-sep`) разделяет их ступенькой внутри этой недели, доходя до левого
  края и разделяя заодно подписи месяцев; заголовок
  дней недели один, липнет сверху при прокрутке (`#calDow`) и разделён
  вертикальными линиями между днями; суббота и воскресенье (`.cal-day--weekend`)
  затемнены смесью `--panel` и `--bg`, чтобы выделить столбцы; подпись месяца —
  вертикальная полоса слева (`.cal-rail`, поворот на 90°), охватывающая строки,
  чей понедельник в этом месяце; у краёв ленты дни соседних месяцев показаны
  как обычные клетки (без приглушения); высота не ограничена — колесо мыши
  прокручивает
  все данные. Кнопки ‹ / › листают на месяц, «Сегодня» — к текущему: первый
  день месяца встаёт вплотную под липкую шапку
  (`calScrollToMonth()`, `calTopMonth()`, `calShift()`; стрелки ←/→ на
  клавиатуре), кнопки периода скрыты. Сегодняшний день выделен диагональной
  штриховкой (`.cal-day.is-today`), его номер — акцентным полужирным.
  Чипсы-события окрашены по формату
  (`fmtCls()`: `cal-ev--online`/`cal-ev--offline`/`cal-ev--hybrid`, цвет —
  `--fmt-*`; без формата — базовый цвет чипса); чипсы в ячейке отсортированы
  по времени начала (события без времени — в конце); в первый день события
  слева
  от названия — время начала (`HH:MM` из `timeOf()`, `.cal-ev-time`), название
  (`.cal-ev-name`) обрезается многоточием; многодневные повторяются
  в каждом дне, каждая дата встречается
  один раз; клик
  открывает карточку, наведение — тултип. Поиск/фильтры
  перепрыгивают к месяцу первого результата, если он не на экране
  (`calJumpToResults()`); при первом открытии лента прокручивается к текущему
  месяцу (`state.calInit`).
- Иконка вкладки и логотип в шапке — `favicon.svg` (OpenMoji, CC BY-SA 4.0);
  название сайта — ML-Gantt.
- Иконки сайтов событий лежат в `icons/` (имя файла = hostname из `url`,
  punycode для кириллических доменов; `.png`, у части событий `.svg`). В шапке
  карточки `renderFull` показывает `icons/<host>.<ext>`: при ошибке загрузки
  пробует `.svg`, затем убирает картинку. Сеть не нужна; для нового события
  иконку кладут в `icons/` тем же именем.
- По горизонтали прокрутки нет: `layout()` в `build()` вписывает весь период в
  ширину окна (`--timeline-w`, шаг по дням — JS `DAY_W`), `--corner-w` — так же
  на лету в `computeCornerWidth()`. Значения в CSS — только фолбэк до первого
  рендера, правка CSS ничего не даст.
- Колонка имён подстраивается под самую длинную строку «название + иконки»
  (замер по `scrollWidth`), названия не обрезаются; на окнах ≤600px — фикс.
  200px.
- По вертикали — обычная прокрутка внутри `.gantt-scroll`; высота строк
  фиксированная (`--row-h`, 62px; на узких экранах 56px), шапка и колонка имён
  липкие.
- Кнопки периода (6 мес … Все; по умолчанию 6 мес, «Все» — крайняя справа)
  отсчитывают последние N месяцев от последнего месяца данных; события, не
  помещающиеся в окно целиком (включая фазы), не показываются — полосы не
  обрезаются.
- Фильтры-переключатели «Актуальные» (`isActual`: событие ещё не закончилось —
  сегодня ≤ крайней даты события и его фаз) и «Записаться» (`canSignup`:
  `registration_iso` не прошёл, а без него — `end` не прошёл) есть только на
  вкладке «Соревнования» (`matches()` применяет их при `state.tab === "comp"`);
  в календаре мероприятий скрыты и не влияют; включаются независимо,
  комбинируются с поиском и не меняют ось периода; пустой результат
  сбрасывается кнопкой. В календаре мероприятий вместо них показывается
  сегмент формата «Все / Онлайн / Офлайн» (`#fmtGroup`, `state.fmt`,
  по умолчанию «Все»), фильтрующий по `fmtCls()`: гибридные события проходят
  и фильтр «Онлайн», и фильтр «Офлайн»; комбинируется с поиском;
  у кнопок формата — цветная точка рядом с подписью (`--fmt-*`; у «Все» точки нет).
- Гранулярность оси: месяцы, пока их ≤ 12 и ширина месяца ≥ 36px, иначе годы;
  ширины ячеек всегда пропорциональны дням (единый масштаб), в годовом режиме
  ось выравнивается по границам лет; позиции полос/линий/«сегодня» считает
  `xOf()` по `CELLS`.
- Чипсы держатся в одну строку: `fitChips()` уменьшает шрифт; чипсой «N треков»
  строка не показывается (число треков есть только в БД как `declared_tracks`).
- Экспорт в календарь — в карточке: ссылки Google (`googleUrl()`, конец +1 день
  — конец эксклюзивен) и скачивание `.ics` (`buildICS()`/`downloadICS()`: VEVENT
  на период + VEVENT «рег. до …», экранирование `, ; \`, фолдинг по 75 октетов,
  `Blob` + `URL.createObjectURL` — без сети). Те же действия доступны иконками
  справа от названия (`CAL_SVG`, `ICS_SVG`).
- Две формы деталей: при наведении на полоску — компактный тултип (`renderTip`:
  название, «📅 С … по …» (у однодневных — одна дата), «🕒 17:00 мск»
  (`timeOf()`: интервал в `time` — как есть; к одиночному `time` конец берётся
  из последнего доклада; при пустом `time` — интервал от первого до последнего
  доклада в `talks`), «⏳ Рег. до …», строки фаз «🏁 Финал 27.11 – 29.11»);
  по клику на полоску, название (псевдоссылка с пунктиром, клик не по всей
  ячейке) или маркер (или Enter/Space на полоске) — полная карточка в модалке
  (`renderFull`, `openModal`/`closeModal`; Esc, клик по фону и крестик закрывают,
  внизу ссылка «Открыть страницу события»). Карточка — две колонки при
  наличии программы (`.tt-cols--split`: справа программа шириной 65%,
  разделитель — вертикальная линия; модалка при этом шире — `modal--wide`,
  1000px) или у соревнований с материалами
  (`.tt-cols--side`: справа «🔗 Открыть страницу события» и материалы,
  разделитель — вертикальная линия; на экранах ≤700px колонки складываются),
  иначе одна (`.tt-cols`): слева иконка
  сайта, описание
  (`description`, только если программы нет), треки списком под заголовком «🏷️ Треки:» (у мероприятий —
  «🏷️ Темы:», `tasks` = `tracks.raw`), приз, участие, формат, язык
  и экспорт в календарь; «🔗 Открыть страницу события» и материалы из
  `links` (снимок таблицы `links`, `null` при отсутствии) с группами
  «📡 Трансляции:», «📦 Решения:», «🎬 Церемонии:», «📺 Видео:», «📰 Статьи:»
  (видео — ролики,
  кроме церемоний) — в правой колонке у соревнований, иначе ниже; справа —
  программа «📋 Программа:» (из `talks`: время —
  название; если времён нет, колонка времени скрывается, `tt-talks--notime`).
  Все внешние ссылки
  открываются в новой вкладке. Иконки
  рядом с названием клик не перехватывают: страница события (`LINK_SVG`),
  Google, `.ics`.

## Ссылки на события

- `url` в `hacks.db` собраны из канала `@ds_private_sharing`. `t.me` из этой
  сети недоступен — не скрейпить напрямую; при дозагрузке использовать
  Telethon-сессию из `../tg_chat_aggregator` (нужен оплаченный прокси из его
  `.env`), только чтение и с паузами.
- Мероприятия (`category='event'`) собраны из открытых афиш: `events.yandex.ru`
  (Яндекс), `developers.sber.ru/kak-v-sbere/events` (Сбер),
  `events.online.gpb.ru` (Газпромбанк; сайт — SPA, данные отдаёт
  `/oerservice/api/v1/events/<id>`, список — `/oerservice/api/v1/events/dashboard`
  с `TimePeriodFilter=1&ClientAccount=gpb`), семинары AGI-in-Russian из
  `agirussia.github.io/workshops.md` — не добавляются: у них нет индивидуальных
  страниц (только общая страница расписания `agirussia.org/workshops.html` и
  одна серия регистрации на `aigents.timepad.ru`), афиша
  ODS `ods.ai/events` (митапы и Data Fest),
  `cloud.ru/events` (Cloud.ru), конференции Онтико `aicasesconf.ru` и
  `ainativeconf.ru`, `conversations-ai.com`. Обновляются вручную с открытых
  страниц.
- Материалы в `links` ищутся в открытом вебе: трансляции — YouTube/VK Видео,
  решения — GitHub/Kaggle/разборы,
  церемонии — YouTube/VK Видео/RuTube, статьи — Хабр/VC.ru/СМИ. В БД попадают
  только реально существующие URL, привязанные к нужному выпуску события
  (год/город); для будущих событий материалов обычно нет.
